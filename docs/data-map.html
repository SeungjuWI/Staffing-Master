헷갈리기 쉬운 말

용어의미
지원 건 vs 지원자지원 건 = 지원서 수 (한 명이 3곳 지원 = 3건) · 지원자 = 사람 수 (3곳 지원해도 1명)
입사 vs 충원입사 = 지금까지 입사한 사람 수 (줄지 않음) · 충원 = 지금 채워져 있는 자리 수 (이탈하면 줄어듦)
기간 필터그 기간에 지원한 사람들만 걸러 보는 것 — 매출·비용·인재풀은 항상 누적

고치면 언제 반영되나

  • 시트나 시스템에서 고치면 화면은 늦어도 1분 안에 자동 반영
  • 화면 위 새로고침 버튼을 누르면 바로 반영 (1분에 한 번만 가능)
  • 시스템 사이의 자동 복사가 3일 이상 밀리면 화면 위에 경고 배너가 뜸

집계 원칙

  • 시트가 원본인 숫자는 시트에서 바로 읽는다 — 복사본을 거치지 않음
  • 채용 단계(합격~입사)는 ktc-support 기록이 기준
  • TO·충원은 Ops 시트 Matching Status가 기준 · 입사는 우리 채용 과정을 거친 사람만

숫자가 이상해 보일 때

  • 먼저 ⓘ 표시로 출처를 확인하고 원본 시트를 열어 대조
  • 화면과 원본은 자동 검증이 33개 항목을 상시 대조하고 있음
  • 그래도 이상하면 슬랙으로 제보 — 지원 미달·시트 오류 알림도 매일 아침 슬랙으로 옴
시트 문서 주소는 이 문서에 싣지 않음 — 대시보드 ⓘ 표시의 링크를 쓰거나 운영팀에 문의.
